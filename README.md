# AI 八股过滤器

给 AstrBot 用的输出过滤器，专门处理 DS/鱼八股和常见 AI 套话。

## 两层

1. **生成前**：在 system prompt 末尾加一段表达禁忌，提醒模型不要用「我记下了 / 这句话稳 / 比之前的都重 / 认下来 / 你掂量 / 首先其次最后 / 综上所述 / 作为一个AI」这类口癖。
2. **生成后**：在 `on_llm_response` 和 `on_decorating_result` 清理 Plain 文本；命中硬短语会按句首/句尾/整句规则删除，命中 AI 套话会去掉过渡词或整句。

## 词库

`lexicon.json`：

- `hard`：字面稀有、基本只会出现在八股里的句子（我记下了、这句话稳、比之前的都重、这条我认、已记录、记进待办……）
- `soft`：太短容易误伤的（稳、我跟、不催、回去睡……），只有在整句恰好等于它时才删
- `short_cut`：网址明确点名的硬切（好、行、行吧、我不嫌、你定、我不理），整句恰好等于就删
- `opener_replace`：好/行/行吧 出现在句首并跟逗号时，去掉开头、保留后半句（好，我知道了 → 我知道了）
- `transition_prefix`：首先/其次/最后/综上所述/值得注意的是/说到底/本质上/某种程度上……
- `filler`：作为一个AI、希望这对你有帮助……
- `era_prefix`：随着……的发展、在当今……背景下
- `let_us`：让我们……
- `not_but`：不是……而是……，默认关闭
- `fiction`：角色扮演/小说八股（嘴角勾起弧度、倒吸一口凉气……），保留但默认关闭；这次不重点收集

`cnmeme.wiki` 的「鱼八股」词条把现象拆成六类，本插件对应处理：

1. **单字硬切**（好/行/行吧/我不嫌/你定/我不理）：单独整句删；`好，我知道了` / `行吧，那就这样` 这种句首硬切只替换开头，保留后半句
2. **认错官腔**（这条我认/我记下了/我记住了）：hard 删除
3. **议论腔总结癖**（先分点、再总结、最后拔高“讲的其实是/本质上”）：过渡词 + hard 短语
4. **穿帮自述**（已记录/记进待办/备选回复/以下是几个版本）：hard 删除
5. **复读固定短语**（麻了/闹麻了/你无敌了/神了/绷不住了）：带梗，**不删**
6. **固定句式**（不是……而是……/总的来说/值得一提的是/某种程度上）：过渡词 + 可选整句删除

## 设计取舍

- 短词只做「整句等于」匹配，避免把「稳定」「我跟着你」误删。
- 单字硬切：单独整句删；`好，我知道了` → `我知道了`，`行吧，那就这样` → `那就这样`。
- 麻了/闹麻了/你无敌了/神了/绷不住了 属于带梗表达，不删。
- 句首/句尾命中时保留同一句里的有效信息；只有短句整句或句中硬命中才整句删除。
- 代码块、行内代码和 URL 会被保护，不会被规则改写。
- 默认兜底改成 `嗯，我在听。`，避免清空后又变成单字硬切。
- 默认不启用小说八股和「不是……而是……」整句删除，避免误伤正常表达。
